# Changelog

## [2.0.0] - 2026-11-25

First version: the Audio, Video and Shadow modules in one options menu.

### Added
- The Back key (ArchNet Input Module) closes this screen cleanly: settings are saved.
- `SettingsService`, `SettingsData`, `SettingsView` (General / Audio / Video pages, Reset, Back), `AudioChannelVolume`.
- Applied at once, saved to `settings.json` on close; display settings on computers only; Quality settings left alone outside Play Mode.
- ArchNet Hub service **Settings**: `GameSettings.cs` and `Settings.prefab` under the Bootstrap; Settings window.
- Edit Mode tests.
